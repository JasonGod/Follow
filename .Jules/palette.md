## 2025-03-05 - [Aria-Label Fallbacks & Keyboard Focus Rings on Reusable Button Components]
**Learning:** In design systems where the global focus-visible outline is disabled (e.g., `:focus-visible { outline: none; }` in `base.css`), interactive custom controls (like `ActionButton` and `IconButton`) must supply their own robust, visible focus indicators (such as `focus-visible:ring-2 focus-visible:ring-accent/40 focus-visible:outline-none`) to preserve full keyboard navigability. Additionally, to avoid redundant or missing accessibility attributes, custom icon-only components like `ActionButton` can automatically use string-based tooltips as fallback `aria-label`s unless an explicit one is passed.
**Action:** Always verify that custom icon buttons have fallback ARIA attributes based on tooltips and explicitly style `.focus-visible` classes when global default outlines are turned off.
