## 2026-08-13 - Custom Titlebar Keyboard Focus and Tooltips
**Learning:** In desktop environments where the custom titlebar is rendered within an interactive/drag region, default browser/OS focus outlines are disabled globally (`:focus-visible { outline: none; }`). Interactive window control buttons (Minimize, Maximize, Close) lack tooltips, ARIA labels, and keyboard focus outlines. Integrating Radix Tooltips within custom layout components requires using `TooltipPortal` to prevent boundary clipping, and using localized labels from the `common` namespace for accessible screen reader feedback. Additionally, titlebar focus trapping/hover triggers can clash, requiring explicit event stop propagation on focus capture to handle focus cleanly.
**Action:** Always wrap custom Titlebar controls in Radix Tooltips with a `TooltipPortal`, provide proper localized ARIA labels, and define explicit inner keyboard focus rings (e.g., `focus-visible:ring-2 focus-visible:ring-inset focus-visible:ring-accent/40`) to ensure Windows and cross-platform accessibility.
