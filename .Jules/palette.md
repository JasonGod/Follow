## 2025-01-24 - Windows Titlebar Accessibility and Focus
**Learning:** In custom Electron titlebars, window control buttons at the screen edge benefit from `focus-visible:ring-inset` to prevent the focus indicator from being clipped by the window boundary. Additionally, `onFocusCapture={stopPropagation}` is necessary to prevent window-level focus handlers from interfering with Radix tooltips on these controls.
**Action:** Use `focus-visible:ring-inset` for edge-aligned interactive elements and ensure `onFocusCapture={stopPropagation}` is applied when integrating tooltips into custom window titlebars.

## 2025-01-24 - Cross-Workspace Type Checking
**Learning:** In this monorepo, the web workspace (`@follow/web`) depends on type declarations generated by the main process workspace (`@follow/electron-main`). Running typecheck on web may fail if the main process types aren't built first.
**Action:** Run `pnpm -F electron-main run typecheck` before `pnpm -F web run typecheck` if encountering "Cannot find module '@follow/electron-main'" errors.
