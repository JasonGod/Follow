## 2024-10-24 - Custom Windows Electron Titlebar Accessibility and Focus Mechanics
**Learning:** In Windows Electron builds, the standard Titlebar is custom-drawn. Because the container is overlayed dynamically on top of the main layout, interactive elements like window control buttons require explicit localized `aria-label` attributes for screen readers, Radix `Tooltip` components using `TooltipPortal` to prevent truncation from overflow-hidden parents, `onFocusCapture={stopPropagation}` to handle focus propagation bugs with Radix Tooltips, and `focus-visible:ring-inset` to keep focus indicators within the button boundaries at the screen edge.
**Action:** When designing or modifying window controls or custom Titlebar-like overlay layouts, always utilize standalone Radix tooltips with portals, localized accessibility labels (such as standard Simplified Chinese terms like 最小化, 最大化, 向下还原), focus interception, and inset rings to guarantee full keyboard and screen reader accessibility.
